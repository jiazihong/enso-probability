方法：状态转移模型（相位年龄分层 + Dirichlet 后验）与历史相似型模型（轨迹近邻核加权）按样本外回测 Brier 技能分组合；两个模型均做"起报月分层 + 经验贝叶斯收缩"以缓解春季预报障碍；90% 区间来自 Dirichlet 蒙特卡洛抽样；未来 ONI 点预测为相似型加权均值（90% 区间为加权分位）；可靠性曲线用于检验概率校准。

说明：概率为历史统计外推，不等于官方季节预报，也不构成决策依据。模型仅使用 ONI 单变量， 未纳入次表层海温、风场与印度洋-太平洋耦合信息；技能分接近 0 的提前期仅可作弱信号参考。
