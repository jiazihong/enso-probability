# ENSO 概率分析工具

基于 NOAA CPC 公开发布的 **ONI（Oceanic Niño Index, ERSSTv5）** 历史序列，估计未来 3/6/9/12 个月
**厄尔尼诺 / 中性 / 拉尼娜** 三种状态的出现概率。纯 Python 标准库实现，无第三方依赖。

## 快速开始

```bash
# 抓取并缓存最新 ONI 数据（写入 data/oni_cache.csv）
python enso_prob.py update

# 输出概率预测（默认 3/6/9/12 个月）
python enso_prob.py forecast

# 附带最近 72 个月 ONI 柱状图，并写出 output/forecast.json
python enso_prob.py forecast --chart --json

# 查看各模型的历史回测技能
python enso_prob.py backtest --horizons 3,6,12

# 生成可视化 HTML 报告（概率条形图 + ONI 历史曲线 + 回测技能表）
python enso_prob.py report

# 运行内置自测
python enso_prob.py selftest
```

需要 Python 3.9+。没有网络时可直接使用仓库中的 `data/oni_cache.csv`；
也可用 `--data-file` 指定本地 `oni.ascii.txt`，用 `--offline` 禁止联网。

## 数据

| 项目 | 说明 |
| --- | --- |
| 来源 | NOAA CPC `https://www.cpc.ncep.noaa.gov/data/indices/oni.ascii.txt` |
| 指标 | Niño3.4 区域海温距平（ERSSTv5），三个月滑动平均 |
| 区间 | 1950 年 DJF 至今，逐月 |
| 缓存 | `data/oni_cache.csv`（带抓取时间戳注释，离线可用） |

## 状态判定

沿用 NOAA 官方定义：ONI **连续 5 个重叠三月**（即连续 5 个月的值）

- `>= +0.5` → 厄尔尼诺（El Niño）
- `<= -0.5` → 拉尼娜（La Niña）
- 其余 → 中性（Neutral）

该规则天然有约 5 个月滞后。因此工具额外输出"临近判定"提示，避免把正在快速增强、
但尚未满 5 个月窗口的事件误读为长期中性。

## 方法

三个估计量相互交叉验证，最终按历史技能加权。

### 1. 状态转移模型

在当前状态 `s_t` 与**相位年龄**（该状态已持续月数，分桶 1–3 / 4–6 / 7–9 / 10+ 个月）条件下统计
`h` 个月后的状态频率：

```
P(s_{t+h} | s_t, age_t) = (N_obs + α) / (ΣN_obs + Σα)
```

- 同龄桶样本权重 1.0，非同龄桶降权至 0.3（分层 + 收缩，缓解稀疏）；
- `α = 4 × 历史边际频率 + ε`，即 Dirichlet 先验后验，避免小样本出现 0 概率。

### 2. 历史相似型模型

以最近 6 个月 ONI 轨迹为查询向量，在过去所有同长度窗口上计算 RMSE 距离，
用高斯核 `exp(-d² / 2bw²)` 加权，统计各近邻 `h` 个月后的状态频率。
带宽 `bw` 取 Silverman 规则并设 0.25 °C 下限，避免权重过度集中在单一历史上。

只使用评估时点**之前**已完整发生的近邻，不存在未来信息泄漏。

### 3. 组合权重

对 1970 年起每分钟滚动起点做样本外回测，计算三分类 Brier 分：

```
BS = (1/3) Σ_i (p_i - y_i)²
技能分 Skill = 1 - BS_model / BS_climatology
```

权重按正技能分比例分配；负技能模型直接剔除（权重 0），两模型均不优于气候态时退化为等权并提示。

### 4. 不确定性区间

90% 区间来自蒙特卡洛：转移模型按 Dirichlet 后验抽样，相似型按有效样本量
`n_eff = (Σw)² / Σw²` 展开为 Dirichlet 后验抽样，两者按组合权重线性叠加后取 5%/95% 分位。

## 自测

`python enso_prob.py selftest` 共 12 项，全部通过：

| 类别 | 检查 |
| --- | --- |
| 规则 | 5 个月阈值触发 / 不足 5 个月不触发 / 拉尼娜判定 |
| 解析 | 列解析与时间排序 |
| 参数回收 | 合成 AR(1) 序列上转移概率误差 `max|Δ| < 0.05`（n≈4500） |
| 蒙特卡洛对照 | 相似型模型在合成序列上的 Brier 技能 > 0.02 |
| 结构对称 | 翻转 ONI 符号后厄尔尼诺与拉尼娜概率严格互换（误差 0） |
| 数值一致 | 概率归一、区间覆盖点估计 |
| 边界 | 缺失值传播、过短序列、相位年龄递推 |
| 回测 | 技能分与 Brier 分自洽 |

## 局限性

- 概率来自历史统计外推，**不等于官方季节预报**，也不构成任何决策依据；
- 模型只使用 ONI 单变量，未纳入次表层海温（WWV）、风场（SOI/信风）、
  印度洋-太平洋耦合与季节锁相等信息；
- 状态的 5 个月判定规则本身滞后，事件初期可能仍显示"中性"；
- 1950 年以前样本缺失，早期观测精度低于卫星时代。
